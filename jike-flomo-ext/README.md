# Jike → Flomo

把即刻网页版（web.okjike.com）改造成 flomo 风格的 Chrome 扩展（Manifest V3，content script 注入，无后端）。

## 需求

打开 `web.okjike.com` 默认进入 `/me`（个人中心），页面呈现 flomo 双栏布局：

- **右侧主列**：顶部 flomo 式输入框（可直接发即刻动态），下方是自己的历史动态（memo 卡片流）
- **左侧边栏**：个人信息、三统计、发帖热力图、导航、圈子标签列表
- 整体居中、米白底（`#fafafa`）、主色绿（`#30cf79`）

**本版范围**：主要做 `/me` 的完整 flomo 化。其他信息流（`/following`、`/`、通知）只套普通 memo 卡片样式，回复/互动点击跳原版帖子详情处理。

### 左侧边栏

从上到下：头像 + 昵称 + 简介（单行省略，悬停看全文；资料异步加载后自动更新）→ 三统计（动态数 / 圈子数 / 注册天数）→ 热力图（近 13 周 × 7 天，按当天发帖数分 0–4 级绿色，hover 显示 `日期 · n 条`）→ 导航（全部笔记/动态/发现/通知，当前项绿底白字，SPA 内部跳转）→ 圈子列表（按发帖数排序，最多 24 个）。

### flomo 输入框

- 出现在 `/me`、`/following`、`/` 主列顶部（fixed 定位，宽度实时对齐主列，空列表也有效）
- 白卡圆角 20px，占位符"现在的想法是…"；默认高 160px，聚焦以 240ms 动画展开到 320px，绿色高亮边框；焦点离开整张卡片后收起
- `ResizeObserver` 同步输入框占位高度，与首条帖子保持 10px 间距；展开时帖子跟随下移；系统减少动态效果设置下关闭动画
- 占位高度写在当前主列，首次插入立即同步；SPA 切换时断开旧观察器，忽略卸载后的零高度回调；CSS 保留最小占位，防止首条笔记被固定输入框遮住
- 图片粘贴、拖放或点击图片按钮选择，显示独立的 96px 方形缩略图；支持删除、继续添加，最多 9 张；PNG/JPEG 原样上传，其他可解码图片转 PNG
- 文字粘贴只插入纯文本，HTML 图片转为附件，不再把大图插进正文；有附件时保持展开，附件多时横向滚动
- 图文草稿按标签页存入独立 IndexedDB（`jike-flomo-drafts`），刷新/导航后恢复，跨页发送不会丢图；图片只在发送时交给即刻原生流程上传
- 底部工具栏 + 字数统计 + 绿色发送按钮；`⌘/Ctrl+Enter` 发送；上传/发送中锁定表单，失败保留草稿并提示

**发帖实现**：不逆向 API，复用即刻原生流程。在 `/following` 用 Lexical `setEditorState` 填文本，将 File 交给原生 Dropzone 的 `onDrop` 上传；从原生表单附件状态确认全部 `UPLOADED`，等原生发送按钮就绪后点击。只有原生表单确认成功/清空后才清除本地草稿。个人页按发送时先保存草稿并跳到 `/following`，通过单一续发标记执行一次；不再强制移除原生按钮的 `disabled`。已有原生草稿时提示处理，避免覆盖。
> 即刻原生发帖框被 CSS 移出视口（`position:absolute; left:-9999px`），**不能用 display:none**，否则 Lexical 失焦。

### 帖子卡片（memo 化）

白卡圆角 12px 无阴影；隐藏头像栏和作者名；时间显示绝对时间（`YYYY-MM-DD HH:mm`，灰色小字）；正文 15px / `rgb(50,50,50)` / 行高 27px；圈子链接浅蓝底、蓝字圆角 `# tag`（位置不变）；操作栏 hover 才显示、只留图标；引用块压平为浅灰小字。

### 本地数据库（IndexedDB）

库 `jike-flomo`，表 `posts`（keyPath `key`，索引 `day`、`ts`），`JF_DB.savePost / allPosts / countByDay`。每条 `{key:id, ts, day, text(≤500), topic, mine, uid, screenName, ...}`；`mine` 只在 `/me`、`/u/*` 页扫描时标记，热力图/统计只算它。

### 数据菜单与初始化

头像信息右上角三横线数据菜单包含：

- **快速刷新**：重新打开自己的主页，重新同步近半年动态并重算统计、圈子列表和热力图；已有更早历史缓存保留。
- **清除数据**：先弹确认，只清除本地动态缓存和同步状态，保留即刻原始内容、图文草稿、个人资料及插件开关。清除后不会被当前 DOM 立即回填；下次打开页面时重新初始化。
- **全量刷新**：先提示完整历史可能需要几分钟或更久，再从最新动态读到明确的最后一页；成功后替换该账号的所有历史缓存并自动刷新，释放原生列表的内存。

**首次初始化**：无同步完成标记时自动进入自己的主页，显示阻止页面操作的 loading 蒙层，解释正在做什么，并显示读取条数、页数、日期。只读取最近六个自然月，最多 60 页；触及页数上限时显示范围提示，更多历史从「全量刷新」读取。支持暂停，之后可从菜单重新同步。

**采集方式**：读取虚拟列表完整的 `props.data`，不依赖屏幕中可见的帖子。分页复用页面原生的 `onLoadMore`，从现有查询观察器读取加载/错误/末页状态，不拼接私有 API。页面查询缓存只保存帖子 id，正文/作者/日期从列表 props 取得。置顶旧帖不会单独触发半年截止。

**保存与恢复**：采集结果暂存，成功后通过单个 IndexedDB 事务替换对应范围，失败/暂停时不替换旧缓存；短范围未读取到的历史不会被删除。按登录账号隔离统计，浏览他人主页不会标记成本人动态，浏览动态流不会抹掉已确认的本人标记。同步期间使用浏览器锁避免多标签页同时重建，完成/清除后通知其他标签页。恢复阅读滚动位置后再解除蒙层。

**状态库**：`jike-flomo-state` 的 `sync` 表按个人主页路径保存同步范围、完成时间、页数、读取条数、是否达到页数上限。初始化依据明确的完成标记，不再使用「已有 200 条」阈值。近半年模式的增量扫描也遵守日期范围。

**自动采集**：初始化完成后，MutationObserver 驱动增量扫描；数据不变时不重画统计。数据持久化，关浏览器不丢。

## 约束

- unpacked 本地加载；隔离环境 `bootstrap.js` 通知后台，后台按开关状态注入 CSS 和 `world: "MAIN"` 的脚本，以读取 React fiber 和 Lexical；关闭状态不注入
- **不逆向任何 API**：帖子数据从 React fiber 的列表 props 取得；原生查询观察器只用于分页状态和原生翻页回调
- 类名带构建 hash（`_post_160sp_5`），一律 `[class*=_前缀]` 匹配
- 即刻是 SPA，路由变化靠 MutationObserver 轮询 tick 重建，不依赖刷新
- 尺寸对标 flomo：侧栏 312px（内容区 288px）、主列 640px、间距 60px；热力格 16px、间距约 6.7px，13 周铺满内容区；月份标签共用网格对齐
- 覆盖原生导航占位、个人页内容上移及容器外边距，避免空白和主列溢出

## 安装

1. `chrome://extensions` → 打开"开发者模式"
2. "加载已解压的扩展程序" → 选 `jike-flomo-ext/` 目录
3. 刷新 `web.okjike.com`（会进 `/me`）

### 一键开关

点击浏览器工具栏的插件图标，直接开启/关闭 flomo 模式，开启时显示即刻风格的黄色底白色 J 图标，关闭时显示灰色底白色 J 图标；悬停提示当前状态。默认开启，设置保存在扩展本地存储，重启浏览器后保留。

切换后自动刷新所有已打开的即刻页面；关闭前先等待图文草稿保存，关闭后使用原版即刻，不再注入样式、编辑框或自动跳转。其他网站不会刷新。

## 调试

改完代码后跑 `./inject.sh` 可免刷新热注入到已打开的即刻页（依赖 browser-harness）。可用 `JF_TAB_ID=<target_id> ./inject.sh` 指定目标标签页；重复注入会清理上一版的观察器。

修改 `manifest.json` 后需在 `chrome://extensions` 重新加载扩展，再刷新即刻页面；热注入只用于当前页面预览。

遮挡问题回归：在没有草稿、列表滚到顶部的即刻页运行 `JF_TAB_ID=<target_id> browser-harness < tests/composer-layout.py`，检查展开/收起、反复导航及输入框卸载重建后的首帖位置，不会发帖。

数据采集逻辑回归：运行 `node tests/data-sync.test.js`，验证半年边界、旧置顶、完整历史、页数限制、取消、账号校验、网络错误及空账号。

图片功能回归：在独立、没有草稿的测试页运行 `JF_TAB_ID=<target_id> browser-harness < tests/composer-images.py`，检查多图粘贴、正文分离、数量上限、删除和刷新恢复，不会发帖。

## 文件

- `manifest.json` — MV3，工具栏 action、后台及即刻页权限
- `background.js` — 持久化开关、角标、按需注入及页面刷新
- `bootstrap.js` — 隔离环境初始化入口
- `db.js` — IndexedDB 封装（`JF_DB`）
- `content.js` — 侧栏注入 + 热力图 + feed 扫描 + 输入框布局 + 原生发送桥接 + 路由
- `data-sync.js` — 数据菜单、确认框、初始化蒙层、分页采集、暂停与同步状态
- `composer.js` — 输入交互、图片附件、草稿保存与发送状态
- `styles/flomo.css` — 全部 flomo 风格覆写
- `inject.sh` — 热更新调试脚本
